# Design System Workflow

Commands for the tuimm-design_system agent: design audits and component checks.

## Available Commands

- `$ds_design-audit` — "design audit", "DS compliance" — Audit Figma files for design system compliance. Read the command from [commands/design-audit.md](commands/design-audit.md)
- `$ds_component-check` — "component check [name]", "compare component" — Compare Figma component with code implementation. Read the command from [commands/component-check.md](commands/component-check.md)
