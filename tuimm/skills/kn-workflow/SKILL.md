# Knowledge Workflow

Commands for the tuimm-knowledge agent: documentation health, runbook generation, and onboarding.

## Available Commands

- `$kn_doc-health` — "doc health", "docs audit" — Documentation health check across Confluence spaces. Read the command from [commands/doc-health.md](commands/doc-health.md)
- `$kn_runbook` — "runbook [topic]", "create runbook" — Generate runbook from incidents and code. Read the command from [commands/runbook.md](commands/runbook.md)
- `$kn_onboarding` — "onboarding [team]", "new joiner guide" — Create personalized onboarding guide. Read the command from [commands/onboarding.md](commands/onboarding.md)
