# Idea: ChatGPT + Canvas para backoffices

Saved from presentation review (Apr 27, 2026). Removed from the Excellence Forum presentation to keep focus, but the idea is solid.

## Concepto

### ChatGPT + Canvas: backoffices sin navegación

- Mitad izquierda: chat. Mitad derecha: canvas con formularios/tablas/gráficos
- No hay menús, no hay rutas, no hay páginas
- Crear un backoffice nuevo = documentar las APIs + configurar los componentes
- Reducción brutal del coste de desarrollo

### Componente AI bot embebido

Widget de chat en webs existentes:
- Ayuda al usuario a entender la web y qué hacer
- Interactúa directamente con la web (rellenar formularios, navegar, explicar)
- Soporte contextual: sabe en qué página está el usuario

**ChatGPT+Canvas** = para lo nuevo. **Componente bot** = para lo que ya hay. Complementarios.

## Por qué se sacó de la presentación

- Es una idea de producto, no de developer tooling — audiencia diferente
- Mezclarla con los agentes y la librería FE diluye el mensaje
- Mejor presentarla por separado cuando tenga más forma
